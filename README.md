📖 Descripción del sistema
--------------------------
Home Finder es una plataforma web desarrollada para facilitar la búsqueda, publicación y gestión de propiedades inmobiliarias.  
Este sistema permite a los usuarios registrarse e iniciar sesión para acceder a funcionalidades como:

- Visualizar datos de casas disponibles (imágenes, descripciones, ubicación, etc.).
- Subir información de una propiedad propia, incluyendo una imagen y su descripción.
- Acceder a una sección de administrador para gestionar usuarios, publicaciones y el contenido del sistema.
- Navegar por una página de inicio que explica qué hacemos, cómo lo hacemos y cuál es nuestra misión.

Todo desarrollado con un enfoque full-stack ligero y aplicable, usando tecnologías web modernas.

------------------------------------------------------------

🚀 Instrucciones de uso
-----------------------

1. Clonar o descargar este repositorio:
   git clone https://github.com/ale12GM/homefinder.git
   cd homefinder

2. Configurar el entorno:
   Asegúrate de tener instalado lo siguiente:
   - PHP (https://www.php.net/downloads)
   - Node.js (https://nodejs.org/)
   - Composer (https://getcomposer.org/)

   Luego, configura tu entorno local:
   - Si el proyecto utiliza base de datos, crea la base de datos en tu servidor local (por ejemplo, XAMPP o InfinityFree).
   - Configura tus credenciales en un archivo de configuración (por ejemplo, config.json o config.php).

   Instala las dependencias necesarias:
   composer install
   npm install

3. Ejecutar el proyecto localmente:
   Puedes iniciar un servidor local con el siguiente comando:
   php -S localhost:8000

   Luego, abre tu navegador y accede a:
   http://localhost:8000

4. Desplegar el proyecto:
   - Si deseas subirlo a producción, puedes usar InfinityFree o cualquier otro hosting compatible con PHP.
   - Sube todos los archivos del proyecto al servidor usando un cliente FTP (como FileZilla).
   - Configura correctamente las rutas y los archivos de conexión a la base de datos.

5. Acceder a la aplicación:
   - Abre tu navegador y entra al dominio de tu hosting (por ejemplo, http://homefinder.lovestoblog.com/)
   - Regístrate o inicia sesión para comenzar a explorar las funcionalidades del sistema.
